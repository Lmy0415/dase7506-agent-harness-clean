When a user revises a goal after tool execution has begun, an agent must identify what still applies and reuse effects already committed. We compare instruction consolidation, plan editing with explicit intent and execution receipts, and a narrowly scoped execution check against three continuation baselines. The methods share a pre-write AppWorld checkpoint on 40 InterventionBench task families. Strict success counts were A 24/40, B 21/40, C 24/40, R 21/40, C+ 22/40, C++ 23/40. The difference for intent-aware editing versus local editing was -5.0 percentage points (95\% paired bootstrap interval [-15.0, 5.0]). The check blocked 0 of 168 evaluated requests. These exploratory comparisons characterize the representation of intent and receipts under a fixed executor and model, with state changes evaluated independently of the agent.
